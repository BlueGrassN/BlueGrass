## 不干扰现有代理

`127.0.0.1:10808` 属于用户现用代理，禁止停止、重启、修改、抢占端口或改写宿主系统代理。用户提醒前仅通过它发送 HTTPS API 请求，没有更改其配置。当前观察到 ProxyEnable=0，ProxyServer=127.0.0.1:10808；这是验证基线，不是要求修改的目标状态。

本轮真实客户端在系统分配的独立回环端口建立本地 HTTP 代理，用显式 HTTP CONNECT 请求进行联调，不进行 WinINET 写入、TUN/WFP 或路由改动。系统代理事务模块仅使用 fake backend 单元测试。

## 实现与验收

1. 真实登录并取得账号资源；由用户给定的预期出口做严格比较，不能用探测结果学习/替代预期值。
2. 锁定 sing-box 1.14.2 Go 依赖，内嵌 SOCKS5 出站；内存持有连接参数，不写配置文件或进程参数。
3. 本地 HTTP 入口业务门默认关闭；受控 HTTPS 探测成功且出口严格相等后才打开。暂停/取消关闭已建立连接；失败无直连回退。
4. UI 与原生子进程通过私有 stdin/stdout 控制，不开放控制 TCP 端口，不将账号 API Token交给原生进程。
5. 真实 API 当前无 expected_exit_ip；测试覆盖只限用户提供的指定资源，并按账号/环境/订阅绑定。通用生产资源仍要求权威字段。
6. 完成受控集成、取消/错误出口/关闭门负向回归，检查原系统代理及10808监听者仍一致，重新构建并更新报告。

出口探测使用 `https://api.ipify.org?format=json`，文档 https://www.ipify.org/ 将该接口明确列为 IPv4。探测只发送普通 HTTPS 请求，不发送业务令牌、节点凭据或用户标识。
