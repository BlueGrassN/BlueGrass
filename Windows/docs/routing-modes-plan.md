# Windows 国内外分流与独立 TUN

日期：2026-10-21。用户要求 Windows 增加类似 v2rayN 绕过大陆的分流及全局模式，并将 TUN 单独呈现为按钮。

## 行为

- 接管方式仍为系统代理或 TUN；与路由模式独立组合。首页提供“国内外分流”“全局代理”选择，连接区域提供单独的“TUN 模式”按钮。
- 国内外分流使用固定版本 geosite:cn / geoip:cn；已知国外域名优先走代理，其余公网未匹配目标也走所选节点。国内域名使用固定国内解析器，其他域名用所选节点上的 DNS；域名解析后使用同一个字面地址做分类和拨号，不二次解析。
- 全局代理保留现有公网经节点的行为；局域网和控制面按已有明确策略处理。出口检测始终经所选节点，不随业务分流转为本地出口。
- 新安装默认国内外分流；已有设置没有 routingMode 时迁移为 global，保持现有行为。连接中禁止修改路由及接管方式，提示断开后切换。
- 新增 profile.routingMode，值仅为 global / bypass_cn；省略兼容旧配置并视为 global。未知或错误类型拒绝，不允许任意路由 JSON 从 API/IPC 注入。
- TUN 直连仅由服务为当前会话的精确公网 IPv4/端口/传输申请许可；其他进程、未授权端点及暂停后的新连接继续被 WFP 阻断。私网、CGNAT、FakeIP 和公网 IPv6 不通过国内直连通道。
- 规则作为带来源、版本、校验值及许可的内置资源分发；不额外创建用户需要配置的文件，不增加自动下载行为。

## 实施与验证

1. 内置并校验 geosite/geoip 中国及国外域名集合，复用固定 Xray matcher；测试域名后缀边界、国内/海外 IP、特殊地址及损坏数据。
2. 扩展界面偏好、连接配置和跨语言契约，验证迁移、独立 TUN 按钮和连接中禁止更改。
3. 添加服务精确直连许可的引用计数、会话回收和错误阻断；测试应用/地址/端口/协议边界。
4. 接入系统代理与 TUN，复用现有物理绑定、FakeIP 及所选节点 DNS；测试两种路由下的真实拨号路径、DNS 与暂停/退出。
5. Go race/vet、Flutter tests/analyze、契约、真实连接及可行的管理员验收。重新打包并安全替换 Windows/dist/BlueGrass-Windows-x64，核对 ZIP 和运行助手。

只修改 Windows 实现及必要手册；不操作 Android、后台生产部署或用户 10808 代理。不改签名校验，不自动重启/休眠，不提交现有脏工作区。
