# Android 0.5.0 流量统计

2026-11-05（Asia/Taipei）。首页新增上传速度、下载速度，以及三个独立累计数值：**总流量、总上传、总下载**。总流量直接取原生累计上传与下载的和，页面不通过速度积分推算累计。

## 统计口径与生命周期

遵循 ADR0041 的本次连接口径：统计由当前 VPN 代理转发的应用 TCP/UDP 有效载荷；方向以客户端为准。局域网/国内直连、DNS、API、规则更新及出口诊断不计入。它是本机业务统计，不是运营商物理流量或官网账单。

原生累计持续工作；首页可见且应用在前台时约每秒采样一次。界面关闭/后台时停止刷新数字。自动网络重连保留累计，同资源暂停后的重试保留可核实数据；主动断开、换资源、换账号及资源到期/撤销结束统计。

原生快照包含会话身份、计数代次、序号、单调时间和十进制字节串。首次采样建立基线，后续有效采样计算速度。丢样、长期后台、异常计数重置、错误身份或乱序数据不会产生假速度峰值。统计故障显示“统计暂不可用”，保留已知累计并标明；不能完整恢复时显示“本次统计不完整”。统计读取不会改变 VPN 资格或连接状态。

## 实现与本次证据

- Go 在业务代理连接的成功读/写处计数，包含部分成功读写；Session.Close 等待已关闭传输的计数操作结束后冻结最终快照，便于 Android 重连前准确结转。
- Kotlin 生命周期线程聚合每个原生核心的累计；单独的只读 `traffic` MethodChannel 调用不会增加控制事件频率。桥接或采样失败不会停止 VPN。
- Flutter 使用 BigInt 保留累计精度；首页保留当前节点身份，并使用原有阴影、浅色/深色卡片风格。
- Flutter 静态检查及 **164 项测试通过**；新测试覆盖速度/累计计算、精度、旧节点迟到回复、后台停止刷新、失败/乱序/计数代次变化、暂停/到期和小屏大字体。
- Kotlin **36 项主机 JVM 测试通过**，包括自动重连、关闭时最后一批字节、采样异常/缺失 JNI、累计回退及身份隔离。Go 全包 race、vet 通过，并使用真实 IO 字节经过原生 TCP/UDP 转发路径核对计数与 DNS 排除。
- 另通过本机 LAN 地址的 TCP/UDP 双向传输，验证实际受保护直连的数据不增加代理计数；测试监听器已随测试关闭。
- 已重建仅 ARM64 的 AAR，检查生成的 `Session.traffic()` JNI 绑定；依赖清单从最终 AAR 的 ELF 重新读取。构建脚本修正 Windows 隐藏驱动器环境变量导致 gomobile 崩溃的问题，仅过滤构建子进程环境。

本次保持 Android Studio/模拟器关闭，没有把主机与组件测试表述为新版 APK 的设备网络验收。历史设备转发证据见先前报告。
