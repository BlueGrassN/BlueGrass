# ADR 0006：首轮 Beta 包含 Windows TUN 与断线保护

- 状态：已接受。
- 决策日期：2026-10-10，Asia/Hong_Kong。
- 对应事项：设计审阅报告 D-06。
- 确认依据：用户选择 B，首轮对外 Beta 即包含 Windows 全局接管和断线保护。

## 决定

1. Windows 首轮对外 Beta 同时提供系统代理、全局接管（TUN）和断线保护。
2. Beta1 对外发放前，Windows 必须完成保护规则、异常阻断、模式切换、正常恢复和独立网络修复工具的验收。
3. 内核或服务异常、TUN 消失、网络切换、已知到期或撤销等故障按保护意图保持阻断；主动断开、正常退出及恢复工具按归属恢复设置。
4. 重启和升级期间的保护行为也纳入首次 Beta 前的验证。补充设计中允许开机早期无保护的候选方案与零泄漏验收之间的冲突，必须在对外发放前解决，不能仅以“已知限制”绕过门槛。
5. 内部 Alpha 可以分阶段集成功能。Beta2 用于扩大用户与设备覆盖、验证兼容性和性能，以及完善恢复体验。
6. 安卓首轮仍提供 VPN；其 App 级保护与系统级保护按主设计分别表述。本项决定 Windows 保护功能的对外测试时机。

## 验收与排期影响

- Beta1 依赖 Windows 网络保护相关任务、泄漏测试和网络修复验证，以及签名安装包、更新和诊断能力。
- 各保护故障场景按实施计划规定重复注入并抓包，禁止流量的泄漏包为 0；网络修复与按归属恢复通过，保护或恢复相关阻断缺陷清零。
- 原先仅系统代理的 Beta1 安排不再采用，Beta1、Beta2、RC 和 GA 日期待依据实际容量及已确认范围重新排定；不把原估算“约延后 6 周”作为承诺。
- 对外 Beta1 的关键路径前移到 Windows 保护实现与验证，不能以先发布、后补保护来满足本决策。
