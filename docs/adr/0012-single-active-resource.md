# ADR 0012：首版同时仅使用一个资源出口

- 状态：已接受。
- 决策日期：2026-10-10，Asia/Hong_Kong。
- 对应事项：设计审阅报告 D-12。
- 确认依据：用户选择 A，首版同一时间连接一个 IP，多 IP 同时使用留到后续。

## 决定

1. 首版 Windows 与安卓客户端同一时刻仅有一个活动资源会话，即一个所选线路/住宅出口。
2. 同一资源允许多个程序和多个网络连接并发使用；该限制不是只允许一个 TCP 连接。
3. 首版不提供“多个资源分别绑定多个本地端口”的用户功能，也不提供多个并行资源的启动、暂停和到期管理。
4. Windows 系统代理与 TUN 均使用同一所选资源，Android VPN 使用当前所选资源。入口 DNS 的多个地址候选仍属于同一资源，不作为自动切换住宅出口的依据。
5. 同一资源的本地代理入口和内部受控探测通道仍按 D-07 实现，不属于用户可配置的多 IP 端口映射。

## 资源切换

- 切换前提示会中断现有连接；用户确认后暂停旧业务，保持已有保护。
- 按 D-05 刷新目标资源资格与配置，按 D-07 验证出口，成功后才开放目标资源的业务转发。
- 失败时保持暂停/阻断并显示原因，不静默改用其他资源或恢复直连。
- 服务端和控制器按会话/请求标识处理快速切换、取消和迟到结果，不能同时放行两个资源。

## 后续范围

多 IP 同时使用及本地多端口功能保留在后续待办，届时单独设计逐资源状态、资格、出口验证、暂停与端口归属，并重新估算。当前统一资源标识与内核适配接口继续保持清晰，但不为未实现的多会话功能增加首版界面和管理流程。

## 验证要求

验证多个程序并发使用同一资源、系统代理与 TUN 的出口一致性、资源切换成功/失败、快速重复切换和迟到结果处理；任何时刻不能同时放行两个住宅资源，也不能因切换失败改走其他出口。
