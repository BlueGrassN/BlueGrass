# ADR 0037：计费网络下载更新须经用户同意

- 状态：已接受，平台网络识别与下载控制待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：补充 D-36；C07、REL-07 的更新下载网络策略。
- 确认依据：用户选择 A，手机流量或计费网络上暂停自动下载，用户同意后继续。

## 决定

1. 普通新版仅在可确认的非手机流量、非计费网络上自动下载安装包。使用蜂窝移动数据，或系统标记当前下载网络为计费网络时，等待用户同意；不能仅凭 Wi-Fi/有线名称推断不计费。
2. 显示“等待允许使用流量下载”，提供“本次允许”和“等待非计费网络”。提示展示包大小及已知剩余下载量；未知时明确说明，不伪造流量估算。检查更新或查看更新说明不等于同意使用流量下载。
3. 下载途中切换到手机流量或计费网络时，若没有本次下载的有效同意，暂停后续包下载并保留可续传进度。确认后按原更新包继续；同意限于本次包下载，不扩展为后续版本永久允许。
4. 因网络策略等待的任务在符合自动下载条件后继续；用户主动暂停或取消的任务不因此自行恢复。断点续传仍须核对缓存与包身份，校验完成后按 D-36 由用户确认安装。
5. 以安装包实际使用的底层网络及其计费状态为准，不把 VPN 虚拟接口误认作免费网络。无法可靠取得相关状态时等待用户确认或明确的非计费网络；具体 Windows/Android 识别、网络切换和在途请求停止能力须验证，不声称切换瞬间零字节消耗。
6. 本限制针对更新包自动下载，不暂停正在使用的代理业务或改变 LAN/DNS 策略。下载清单、检查更新与安装授权继续按原有流程分别处理；本次不新增后台服务或执行实际下载。

## 验证要求

- 覆盖普通 Wi-Fi/有线、计费 Wi-Fi/有线、手机流量及无法识别网络的情况；未获同意时不启动包下载。
- 覆盖下载中切网、网络恢复、选择本次允许、等待、取消与后续新版本；网络暂停与用户暂停能正确区分，同意不泄漏到其他更新包。
- 验证实际下载路径、切网后的停止与续传、缓存及包校验；等待网络和下载恢复都不触发安装、维护暂停或中断现有业务。
- 本轮仅同步设计，未执行平台网络测试或下载安装包。
