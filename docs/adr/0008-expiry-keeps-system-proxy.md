# ADR 0008：到期自动暂停时保留系统代理

- 状态：已接受。
- 决策日期：2026-10-10，Asia/Hong_Kong。
- 对应事项：设计审阅报告 D-08。
- 确认依据：用户选择 A，自动停止后保留系统代理并暂停业务转发，由用户选择恢复方式。

## 决定

1. Windows 系统代理模式下，收到明确到期、停用或撤销信息，或达到已知有效期时，进入“已暂停”。
2. 立即终止该资源现有的代理业务连接，并拒绝新的业务转发；系统代理保持指向本产品已占有的回环入口，不自动恢复接管前的设置。
3. 正常的自动暂停保留本地监听并明确拒绝转发，避免把暂停实现为关闭端口后仍让系统代理指向无人监听的端口。后台服务负责转发门槛，用户界面负责按用户生效的系统代理设置。
4. 自动暂停与用户主动断开使用不同的生命周期语义。到期、撤销或界面进程异常退出不能被解释为用户要求恢复网络。
5. 界面说明暂停原因，并提供续费、切换有效资源、手动恢复网络和离线客服入口。
6. 用户主动断开、选择恢复网络或正常退出时，按归属恢复接管前的系统代理快照；若其他软件已经修改设置，不覆盖其新值。

## 恢复流程

- 续费或切换资源后，按 D-05 重新取得有效资格与连接配置，再按 D-07 验证实际出口；全部通过才恢复业务转发。
- 暂停期间需要打开官网续费时，明确提供“恢复网络并打开官网”，由用户主动触发恢复；不自动为外部浏览器增加绕行权限。
- 控制面登录、网页取数和必要诊断继续遵循既定直连路径；不能把这些路径用于普通业务转发。
- 失效凭据和缓存配置按现有生命周期清理；暂停状态保留恢复所需的资源标识、原因和代理快照。

## 适用边界

- 系统代理只影响遵循其设置的程序；此行为不等于 TUN 全局断线保护。
- TUN 模式下的自动停止继续保持已有 WFP 保护，按用户动作恢复。
- “恢复网络”指恢复接管前设置，原设置可能是其他代理，不保证一定变成直接联网。

## 验证要求

到期和撤销后已有代理业务连接终止、本地入口保持监听并拒绝新转发、系统代理值不变；不会在暂停期间产生上游业务流量。覆盖界面异常退出、续费、换资源、验证失败、主动恢复、正常退出及其他软件修改代理的情况。恢复成功前必须再次通过资格和出口验证。
