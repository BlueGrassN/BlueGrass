# ADR 0047：到期提醒覆盖账号全部当前归属资源

- 状态：已接受，全量到期摘要契约、同步与平台验收待完成。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C01/C03/C08；细化 D-46 的提醒对象范围。
- 确认依据：用户选择 B，所有当前归属账号的资源都提醒，包括近期未使用的资源。

## 决定

1. 当前已登录账号仍持有的全部资源纳入提醒范围，不限于当前选中、最近成功连接、当前可连接、当前筛选结果或已加载的列表页。
2. 按 D-25 的当前归属规则处理：从未使用、仅静态 IP、开通中、不可连接及到期未回收的资源均不因连接状态被排除；已回收/转出资源移出提醒范围。只有具备有效明确到期时刻的资源才安排 D-46 四档提醒，null 不编造日期。
3. 采用对应客户资源/订阅的业务到期时刻，不拿上游设备、原始 IP 或其他记录的日期代替。提醒不授予连接资格、不自动选择资源、建连或打开官网，当前连接仍独立执行到期暂停。
4. D-46 的 7/3/1 天及到期档、每资源/到期时刻去重、跨档补偿及更新后撤销旧任务继续适用。提醒与页面筛选、排序和分页位置分离，浏览到哪一页不能决定哪些资源会收到提醒。

## 取数与同步契约

- 需补只读的全量到期摘要能力，可作为完整资产接口的轻量投影；返回带类型的稳定资源标识、必要展示名称、当前归属/状态、客户到期时刻或 null，以及同步顺序和完整性所需元数据，不携带节点密码或完整连接配置。实际路径、字段和一致性规则须在 C01/S1 定稿，不能混入当前 API 响应示例。
- 当前 `/nodes` 及其详情只承接合格连接节点，无法证明账号全部资产的到期覆盖。不能把缺席节点解释为无资源、已回收或无需提醒；接口未补齐前，该功能仍是未完成的首版契约。
- 登录及恢复有效账号会话后，业务数据层后台按游标、限并发分批同步全部摘要。页面仍按需加载完整资源；提醒同步独立继续到完整性条件满足，不为此批量获取连接凭据或阻塞首页首次可用。
- 客户端运行且平台允许同步时，沿用每 30 分钟加 ±5 分钟抖动的后台刷新节奏；前台恢复按既有刷新策略检查，合并重叠任务。网络失败/429 沿用退避，记录完成范围、游标与同步时间；局部成功不声称覆盖完整账号，不能据此全量删除未返回的旧任务。
- 删除任务需当前归属的权威变更或接口契约保证完整一致的快照证据。新到期值、重新归属和迟到旧响应按资源同步顺序处理，不让旧数据恢复已取消的提醒。
- 账号令牌仍由既定业务数据层持有，Windows 特权服务不因全量提醒获得账号令牌。应用退出、离线或系统后台限制时，未知的新资源/新有效期不能假装已同步；已有计划及恢复补偿按 D-46 的平台边界验证。

## 展示与验证

- 通知和应用内提示能定位到对应资源，即使它不在“可连接”视图中；由资源详情或全部资源视图承接，不能用通知绕过归属复核。
- 后续 [D-48](0048-grouped-expiry-notifications.md) 确认多资源同时触发时合并一条摘要，点击查看对应到期清单；每条资源的提醒资格、档位和去重记录保持独立，分页结果不各自生成重复摘要。
- 验证首次加载仅一页时后续页资源仍纳入计划，以及从未连接、不可连接、到期未回收、null、明确回收/转出和重新归属的处理。
- 覆盖部分分页成功、空页有后续、断网续传、同步乱序、到期更新、筛选变化、退出账号与跨账号隔离；未知覆盖范围不得显示全量完成。
- 本轮只同步设计，没有实现摘要接口、读取生产资产或注册实际通知。
