# ADR 0040：资源列表默认优先显示最近成功连接的资源

- 状态：已接受，本地使用记录、排序与分页合并待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C01/C08；补充 D-23/D-39 的列表展示。
- 确认依据：用户选择 B，最近成功连接过的资源优先，其余保持接口返回顺序。

## 决定

1. 默认列表先显示本机有成功连接记录的资源，按最近成功连接的先后逆序排列；没有记录的资源保留接口原有相对顺序。筛选先于排序，默认可连接视图与全部资源视图均遵循相同规则；用户显式选择其他排序时按其选择展示。
2. 只有当前连接完成资格、认证、实际访问及固定出口验证，并被原生层确认进入“已连接”后，才更新该资源的最近成功记录。预选、点击、认证成功但出口失败、取消、诊断通过以及旧连接的迟到事件都不更新排序。
3. 每个资源仅保存最近一次成功的本地顺序记录，按操作系统用户、服务环境、数据源及账号隔离，以带类型的稳定资源标识关联。顺序持久化且不依赖本机墙钟排序，重复成功事件幂等处理；不保存访问明细、凭据，也不上传为使用行为统计。
4. 历史记录只影响排序，不证明当前资格。已到期资源仍按 D-23/D-25 的视图和归属规则展示；已回收或转出的资源不能因本地记录重新出现，列表某页缺失也不能直接认定已回收。
5. 分页保留接口的原始游标及返回顺序，展示层合并、去重后排序；不能用重排后的最后一行生成下一页游标。最近项可能在后续页，按当前显示需要、限并发地优先通过稳定标识核实最近资源，不为排序全量拉取资产。
6. 当前可连接节点可使用已有单条详情端点核实；完整资产、分组及其他筛选仍依赖待补契约。未核实条目不得仅凭历史判为可连接，失败和缓存展示沿用同步状态规范；缺少必要筛选字段时不编造匹配结果。
7. 重排只改变显示位置，不改变已选资源或原生连接。条目使用稳定标识承接点击，避免刷新或排序变化导致点击到另一资源。首次无历史时自然沿用接口顺序，D-39 的预选及 D-10 的自动连接规则继续成立。

## 存储与验证

- 本地记录在客户端重启后保留，清除对应账号本地数据或卸载时删除；其他账号/数据源不能读取或继承该顺序。不建立完整连接历史页面或跨设备同步契约。
- 验证先成功连接 A、后成功连接 B 时 B 在前；A 失败、仅预选或诊断不会置顶；同资源重复事件及本机时间回拨不改变正确的成功先后。
- 覆盖最近资源位于后续页、详情先到/分页先到、重复记录、空页有后续、过滤及完整资产视图，原接口分页不漏项、不重复、不因排序改写游标。
- 验证到期/归属变化、账号切换、重启、主动清理、列表重排时的选中项与点击目标；本轮仅同步设计，未修改 API 查询或实现客户端排序。
