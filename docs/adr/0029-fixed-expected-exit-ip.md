# ADR 0029：每个资源使用固定且唯一的预期出口 IP

> **2026-10-12 用户修正：Windows 客户端不再执行本文的固定出口前置校验。** 用户要求有完整节点信息就连接，随后经该节点检测实际出口并显示；缺少预期 IP 或检测结果不同不得阻止连接。当前规则见 [Windows 连接后出口检测](../../Windows/docs/observed-exit-flow.md)。以下保留为历史决定，不能用来重新引入 Windows 出口门槛。

- 状态：已接受，API 字段、客户端比对与运行验收待完成。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：全项目复核 C05；B-04、S11 的资源与预期出口对应关系。
- 确认依据：用户选择 A；每个资源对应一个确定的出口 IP，检测结果必须与其一致。

## 决定

1. 每个资源具有固定且唯一的预期出口 IP，由业务 API 的权威资源配置提供；它表示通过该资源后外部网站看到的地址，不是中转入口地址。
2. 首次连接、资源切换和重连都须经所选资源完成出口检测，并将实际 IP 与该资源的预期 IP 比对；一致且其他资格检查通过后才放行业务。
3. 实际 IP 不匹配时返回 CONN-005，业务继续关闭并保留已有保护。不得自动接受检测到的新地址作为预期值，也不按国家、城市、网段或“同一个供应商”放宽比较。
4. 缺少或无法解析预期 IP 时，属于配置/契约不完整，不能进入“已连接”或跳过比对；使用 SYNC-003 表达当前配置字段异常，并提供刷新或排障入口。
5. 两个地址按解析后的 IP 值比较，不能只比较字符串。[D-33](0033-current-ipv4-egress.md) 确认当前资源全部为固定 IPv4 出口，预期字段及探测均采用 IPv4；入口地址族独立验证。不能由一次出口匹配推断所有业务能力均已验证。
6. 预期值与资源身份及当前配置绑定。旧资源、旧连接尝试或乱序配置的值不能覆盖当前值；验证完成前继续检查资源身份、资格和有效期。
7. 检测端点失效时可按 D-28 使用备用端点；已取得有效但不匹配的出口结果时，按 D-07 拒绝放行，不能通过挑选另一个有利结果隐去不匹配。用户重试按新的受控验证尝试处理。

## API 与原生层契约

- 目标节点/连接配置增加单值 `expected_exit_ip`，当前类型为 IPv4 字面量字符串（D-33）；可连接资源必须提供。客户端映射为领域模型的 `expectedExitIp`，并通过 `exitCheck.expectedExitIp` 传给原生层。
- `host`/`port` 继续表示中转入口。源表哪个字段能权威提供预期出口、其与资源身份的映射由 B-04/S1 核实；本次用户确认固定出口语义不等于已验证某个数据库字段。
- 当前 Go API 尚无 `expected_exit_ip`，必须先补齐接口才能满足本决定的正式连接验收。本文不将规划字段混入当前响应示例，也不声称现有服务已支持。
- D-28 检测服务独立观察请求来源 IP，不从客户端提交的预期值生成“实际出口”；比较在客户端原生层完成，不向检测服务传账号或节点凭据。
- 现有逻辑会话在 D-15 允许的条件下使用缓存时，也只能使用该会话最近验证配置中的预期值，不能以探测结果补造缺失值或延长已知资格。

## 对既有设计的更新

D-07 原先的“仅在可靠预期值可用时比对”被本决定细化为固定出口必比。实际出口检测、失败阻断、独立检测服务和备用端点继续保留；主设计、ConnectRequest、字段映射和质量门禁同步采用必需预期值。

## 验证要求

- 预期 IP 正确且实际结果匹配时可通过；实际结果不同、预期缺失或格式错误时不得放行业务。
- 等价的合法 IP 文本表示按地址值比较；不同 IP 不因地区相同而通过。地址族组合及未知能力不误判为已支持。
- 不能用入口 IP、首次探测 IP 或旧资源的预期值代替服务端当前权威配置。
- 覆盖首次连接、切换、重连、缓存恢复、端点失败、有效不匹配结果、取消及迟到响应；结果只作用于对应连接尝试。
