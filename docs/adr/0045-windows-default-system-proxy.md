# ADR 0045：Windows 首次默认系统代理并记住模式选择

- 状态：已接受，模式偏好与原生状态联动待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C06/C08；Windows 首次连接、模式切换及恢复。
- 确认依据：用户选择 B，首次默认系统代理，需要时手动开启全局接管，之后保存用户选择。

## 决定

1. Windows 在没有已保存模式、原生会话或待恢复保护意图时，初始选择 `system_proxy`，全局接管开关关闭。D-39 的资源预选不改变模式，也不发起连接。
2. 用户可手动选择系统代理或全局接管；偏好按本机操作系统用户保存，重启、登录切换及升级后保留。新逻辑会话使用保存的选择，主动断开不把偏好重置成系统代理。
3. 未连接时调整模式只保存偏好，不立即设置系统代理、创建 TUN 或启动业务；仍由用户点击连接，或按已明确开启的 D-10 自动连接规则开始新会话。保存模式不自动开启自启或自动连接。
4. 启动界面先读取原生当前会话和保护意图，已有 TUN/系统代理会话按其真实状态展示与恢复；不能用首次默认值或界面偏好覆盖正在运行的模式、解除已有保护或重复连接。
5. 连接期间切换模式作用于同一资源，沿用原生受控切换、资格/出口验证及失败回滚。用户期望的模式与实际运行模式分别记录；失败时显示“全局接管未启动”等真实结果，不把保存偏好当成切换成功，也不自动改写用户选择来掩盖失败。
6. 只有原先已验证且仍有效的系统代理会话，才可在开启 TUN 失败后按既有规则保留原连接。以保存的 TUN 模式新建会话失败时，不静默改用系统代理放行业务；已有保护按既定恢复流程处理。
7. 系统代理只覆盖遵循代理设置的程序，不能宣称统一接管公网 UDP 或全部应用。界面在模式入口说明这一范围并提供手动全局接管入口；LAN、内网 DNS、IPv4 出口及公网 IPv6 规则继续按 D-31～D-34 分模式执行。
8. D-06 的首轮 Windows Beta 仍须交付并验收系统代理、TUN 和断线保护，初始默认值不缩减功能范围。Android 继续采用既定 VPN 模式，不套用 Windows 的系统代理默认值。

## 验证要求

- 全新用户首次连接采用系统代理；保存 TUN 或系统代理后跨重启/升级仍保留，未连接时改偏好不会自行接管网络。
- 覆盖已有原生会话、保护恢复、用户主动断开、自启/自动连接开关及首次资源预选；默认值不覆盖运行意图或触发额外连接。
- 覆盖连接中双向切换、TUN 启动失败、新会话 TUN 失败及回滚；选择、实际模式和提示一致，不静默降级或解除保护。
- 本轮仅同步设计，未修改设备代理设置、启动 TUN 或实现客户端。
