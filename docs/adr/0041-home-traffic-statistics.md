# ADR 0041：首页显示实时速度与本次连接流量

- 状态：已接受；Android 0.5.0 已实现原生统计、通道传递及首页显示，验证范围见[2026-11-05 验收](../../Android/docs/traffic-verification-20261105.md)。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C03/C08；首页、通用内核适配接口与状态事件。
- 确认依据：用户选择 A，首页显示实时上传、下载速度及本次连接累计流量；仅本地连接统计，不作为官网计费数据。

## 展示与计数口径

1. 首页展示上传速度、下载速度及本次上传/下载累计量，可同时显示两者合计。方向以客户端为准；速度使用 `B/s`、`KiB/s`、`MiB/s`，累计使用 `B`、`KiB`、`MiB`、`GiB`，单位随数量变化。
2. 统计当前账号、所选资源及本次逻辑会话中实际经中转转发的应用业务 TCP/UDP 数据，在原生适配层的统一业务数据计数点按成功读写字节计数。不重复累计入站与出站两侧，不计代理协议封装、握手或底层重传；这不是服务端已接收数据量或物理网卡流量。
3. 本地 LAN/回环、未使用代理的流量、API/更新等直连控制请求，以及受控出口/UDP 诊断探测不纳入该业务计数。系统代理模式仅显示进入本产品代理的业务，不能宣称代表全机流量。
4. 数据来自本机原生服务/VPN 内核适配层，不新增业务 API 流量查询或计费字段，不上传使用统计或记录访问目标。采样失败不改变连接资格或保护状态。

## 会话与界面生命周期

| 情况 | 行为 |
| --- | --- |
| 新逻辑会话 | 累计从零开始；出口验证前普通业务保持关闭，探测不计入。 |
| 同一资源故障重连、切换底层网络或重新打开界面 | 同一逻辑会话继续累计；界面重建先读取原生累计快照，不自行归零。重连期间速度按真实业务转发状态显示。 |
| 主动断开、切换资源、登出，或到期/撤销结束会话 | 结束旧会话计数，首页清空旧累计；未连接显示零速度/零累计，下一次新会话重新计数。不能把旧资源数值放到新资源卡片。 |
| 已有会话但统计未就绪或采样失败 | 速度或累计的受影响项显示“— / 统计暂不可用”；已有可靠累计可保留并标为上次数据，不把缺失样本解释为零流量。 |
| 原生进程/系统重启导致计数无法连续恢复 | 仅累计可核实部分并标注“本次统计不完整”，不得把恢复后的片段伪装成完整会话总量；会话资格与恢复仍按 D-15 执行。 |

首次有效样本建立基线，取得同一计数代次的后续样本后计算速度。界面可见时目标约每秒刷新一次；界面隐藏/后台时降低或停止界面推送，原生累计继续，不为刷新数字持续唤醒界面。平台采样开销由 S4/S7 验证。

## 原生事件契约要求

- 累计由原生层唯一维护，快照带账号/数据源归属、稳定资源标识、逻辑会话标识、计数代次、序号、单调采样时间、上传/下载累计字节及有效性/完整性标记。`GetStatus`/状态订阅及 Android 对应接口须能提供这些信息，具体共享结构由 C03/S6 定稿。
- 界面采用累计快照，不因丢失或重复事件重复加总；只接受当前会话的较新样本。速度按同一计数代次的字节差除以单调时间差计算，墙钟调整不制造速度尖峰。
- 计数重置、倒退、乱序、长时间无有效采样及进程代次变化须重新建基线并标明缺失范围，不跨未知间隙拼出“实时速度”。累计字节按足够宽的整数传递，防止跨语言精度损失。
- 锁定内核版本后，S4/S7/S12 验证各协议可取得符合口径的计数；不能直接把包含 LAN、诊断或重复流量的全局/TUN 计数冒充本次业务统计。当前仓库尚无该原生客户端实现。

## 验证要求

- 用受控 TCP/UDP 双向业务核对方向、单次计数、单位和累计，单独验证 LAN、控制请求及诊断被排除；不是主动测速或带宽上限测试。
- 覆盖空闲、连接前验证、同资源重连、界面关闭后重开、切换资源、主动断开、到期及原生重启；当前状态与计数归属一致。
- 覆盖丢样、重复/乱序事件、计数重置、时钟变化和大累计值；不可用/不完整不显示成精确的零或完整总量，统计失败不打断业务。
- 2026-10-11 本轮只同步设计；Android 后续实现和测试见上述 2026-11-05 验收记录。
