# ADR 0043：首页默认完整显示出口 IP

- 状态：已接受，首页展示与连接状态联动待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C05/C08；细化 D-29/D-33 的出口信息展示。
- 确认依据：用户选择 A，首页出口 IP 默认完整显示，方便核对当前出口。

## 决定

1. 首页默认显示完整出口地址，不隐藏部分地址，也不要求点击才能查看。当前资源按 D-33 为固定 IPv4，地址与其来源、验证状态分别展示。
2. 尚未连接或正在验证时，已取得的权威配置值标为“预期出口 IP”；不能在探测前把该值写成“实际出口已验证”。预期值缺失/无效时显示未提供/配置异常，不用中转入口、展示资产地址或本机公网 IP 填补。
3. 当前连接通过 D-07/D-29 的资格及固定出口校验后，完整显示实际出口并标注已验证。重连、暂停、断开或切换资源后不沿用旧的当前验证状态；若展示历史结果，须明确标为上次验证及对应时间/资源。
4. 实际出口不匹配时，在错误详情中分别完整展示预期值和本次检测值，按既有规则拒绝业务放行；无效响应不伪装为有效检测 IP。旧资源或旧连接尝试的迟到结果不能更新当前卡片。
5. 页面显示完整地址不改变凭据脱敏、诊断导出前可选 IP 掩码或上报范围，也不自动写入剪贴板。完整显示本身不触发新增探测或周期性检测。

## 验证要求

- 覆盖预选未连接、连接验证中、成功、重连、暂停、断开及资源切换；地址完整，预期/实际/历史与验证标签正确。
- 缺失字段、入口与出口不同、不匹配、无效响应及迟到结果均不产生虚假的已验证状态；浅色/深色及窗口宽度变化不截掉地址的关键部分。
- 本轮仅同步文档，未实现客户端展示或执行出口探测。
