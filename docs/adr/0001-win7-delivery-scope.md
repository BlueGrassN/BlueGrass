# ADR 0001：Win7 后续独立交付并保留完整网络能力目标

- 状态：已接受。
- 决策日期：2026-10-10，Asia/Hong_Kong。
- 对应事项：设计审阅报告 D-01。
- 确认依据：用户在本轮决策中选择 A。

## 背景

主设计已确认支持 Windows 7 SP1 x64，系统代理、TUN 和断线保护均属于兼容版的能力目标。审阅报告曾建议按用户占比决定是否启动 Win7，并将其首版缩小为系统代理模式，需要明确交付顺序和范围。

## 决定

1. Windows 10/11 主力版与安卓版先发布。
2. Win7 兼容版随后独立开发、验证和发布，不作为主力版与安卓版的首发依赖。
3. Win7 保留系统代理、TUN 和断线保护目标，不缩减为仅系统代理版。
4. 不以 Win7 用户占比达到 5% 作为是否交付的门槛。
5. Win7 的具体启动时间、发布日期和工作量另行规划；本决策未确认“GA 后 4 周”的固定时间。

## 备选方案

- 三个平台同期推进、同期发布：未采用。
- Win7 后续仅提供系统代理：未采用。

## 影响

- 主力版与安卓版的当前排期继续不计入 Win7 开发工作量。
- 原先仅系统代理方案的估算不能用于本次确认的完整能力目标，需要重新估算。
- Win7 的内核、工具链、驱动、系统过滤和恢复流程仍须独立验证。本决策不代表这些能力已经验证通过。
- 主设计中的 WPF + .NET Framework 4.8 + Xray 路线继续作为 Win7 的现有方案；共享 Go 原生层仍只是候选，须验证并另行记录决定。
