# ADR 0044：普通更新就绪采用应用内提示

- 状态：已接受，界面与更新器状态联动待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：细化 D-36；C07/C08、REL-07 的更新就绪提醒。
- 确认依据：用户选择 A，普通更新下载完成后使用应用内横幅或角标，用户方便时点击安装。

## 决定

1. 普通更新包下载完整且通过校验后，在首页显示“更新已就绪”横幅，并在关于/更新入口显示就绪状态或角标；不主动弹出模态安装提醒、不抢窗口焦点或将后台窗口拉到前台。
2. 用户点击提示可查看版本信息及安装入口，明确选择“立即安装”后才进入 D-13/D-36 的安装流程。忽略、收起提示或客户端重启都不视为同意安装，也不停止当前连接。
3. 横幅可以收起或稍后处理；关于页保留就绪状态及安装入口。同一版本不因反复激活窗口而反复展开已收起横幅；再次启动仍须核对缓存包有效性，已失效的包不能保留可安装提示。
4. 就绪提示不遮挡连接按钮、保护阻断、出口不匹配或资源到期等当前操作与状态。安装后更新版本/缓存状态，移除已完成版本的就绪提示；新包仍须通过完整校验。
5. 本决定只规定普通更新就绪提醒，不扩展为系统级推送通知；平台下载任务所需的运行通知不属于安装催促。最低支持版本限制及用户主动触发安装后的平台授权继续按原设计执行。

## 验证要求

- 前台、后台、托盘隐藏及已连接状态下包校验完成，仅更新应用内就绪状态，不弹模态提醒、不抢焦点、不主动安装或暂停连接。
- 覆盖收起后重新进入、客户端重启、包校验失效、用户明确安装、安装完成及新版本替代，入口状态与实际可安装包一致。
- 两种主题下横幅、角标和安装入口清晰且不覆盖主要连接状态；本轮仅同步文档，未实现界面或触发下载/安装。
