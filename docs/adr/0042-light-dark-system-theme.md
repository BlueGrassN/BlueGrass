# ADR 0042：浅色与深色主题，默认跟随系统

- 状态：已接受，主题资产、界面实现及跨平台验收待完成。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C08；U-01/U-05 的主题与设置。
- 确认依据：用户选择 A，支持浅色、深色，默认跟随系统，也可手动切换。

## 决定

1. 设置页提供“跟随系统 / 浅色 / 深色”三个选项，首次安装默认“跟随系统”。Windows 主力版与 Android 首版采用同一产品规则，后续 Win7 版按实际平台能力适配。
2. 跟随系统时，应用启动及系统主题变化后采用对应浅色或深色外观；无法取得系统主题时使用浅色作为显示回退，保存的选项仍为“跟随系统”。
3. 手动选择浅色或深色后，系统主题变化不覆盖该选择。切回“跟随系统”时立即采用当前系统主题，不要求重启客户端。
4. 保存用户选择的模式，而不是只保存当前解析出的明暗颜色。主题偏好按本机操作系统用户保存，未登录页面也生效，重启、登录切换与应用升级保留；不依赖业务账号或远程配置。
5. 主题切换只更新应用外观，保持当前页面、输入内容、所选资源、连接、保护及统计会话。不得为切换主题重启内核、重建连接或重置统计。
6. 登录、首页、资源列表/详情、设置、诊断、更新提示和应用内弹窗都提供对应主题。文字、图标、选中态、焦点及错误/保护状态须可辨识，不仅以颜色区分状态；品牌素材与具体配色在视觉稿中落实。
7. 系统安装、VPN 授权等系统管理界面的外观遵循平台能力，不将应用主题选项解释为修改整机主题。先恢复已保存偏好再展示主要界面，避免手动深色启动时出现不必要的浅色闪屏。

## 验证要求

- 覆盖首次启动默认跟随系统、运行中系统明暗变化、手动覆盖、切回跟随系统，以及无法取得系统主题时的回退。
- 验证重启、未登录、切换账号和升级后保留用户模式；两个操作系统用户的偏好不串用。
- 浅色和深色均检查页面、弹窗、文本输入、加载/空/错误/保护状态、图标、键盘焦点与对比度；切换后连接与输入状态保持。
- 本轮仅同步设计，尚未生成视觉稿或实现客户端主题，不表示视觉与平台验收已通过。
