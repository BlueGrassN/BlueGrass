# ADR 0048：同时触发的资源到期提醒合并为摘要

- 状态：已接受，摘要状态、通知投递与跳转待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：C03/C08；补充 D-46/D-47 的多资源提醒方式。
- 确认依据：用户选择 A，多个资源同时触发提醒时合并一条摘要，点击查看各资源到期信息。

## 决定

1. 同一用户、环境/数据源及账号在同一轮到期评估或恢复补偿中触发的多条提醒，合并为一条系统摘要，并以应用内汇总提示承接；不为每条资源分别弹出通知。不同账号的资源不合并。
2. 摘要显示本轮涉及的资源数量，按到期/临近到期档位区分，不能把部分已到期写成全部已到期。资源过多时系统摘要只保留数量及简要信息，完整名称、到期时刻和当前状态在应用内查看，时间按 D-38 显示。
3. D-47 的分页同步结果进入同一轮摘要集合，不能每收到一页就新发一条通知。迟到页面只更新该轮摘要；摘要身份保持稳定，不因重试或同轮补充结果反复新增提醒，平台更新行为须验证。部分同步时只报告已知提醒数量，不把它当作账号总资产数或声称全量同步完成。
4. 每条资源继续使用 D-46 的资源/到期时刻/档位去重键。摘要记录实际包含的键与提交状态；只有被有效摘要包含且平台接受提交的项才更新系统提醒记录，不能因为发送了一条摘要就把其他待发项全部标为已提醒。
5. 投递前复核成员仍属于当前账号、当前到期时刻与档位；新到期值或归属变化取消旧项，摘要随之更新，已无有效成员时撤销相应待发/可管理通知。重复投递、进程恢复及摘要更新不重复消费提醒项，权限拒绝/投递失败不伪造成功。
6. 多资源摘要点击后打开“全部资源”的对应到期清单，可逐条进入详情；不受默认“可连接”筛选限制。只有一条时可直接打开该资源详情。入口按当前账号及最新状态核对成员；状态变化时说明已更新/不可用，不从旧通知恢复资格或显示其他账号数据。
7. 合并只改变呈现方式，不改变全部当前归属资源范围、7/3/1 天及到期档、错过多档只补当前档的规则。不会因等待合并而延后原生到期暂停，也不自动打开官网、发起续费或连接资源。

## 验证要求

- 同轮多资源及不同提醒档位只产生一条准确摘要，各成员去重独立；单资源、摘要超长、账号隔离与应用内完整清单可用。
- 覆盖分页分批到达、空页有后续、部分同步失败、重试、摘要更新、平台拒绝、进程恢复及迟到结果，不重复提醒或把未包含资源标成已提醒。
- 覆盖提交前后有效期/归属变化、摘要成员全部失效、点击旧通知及切换账号；通知导航只展示当前允许查看的数据，原到期暂停不受影响。
- 本轮只同步设计，未注册通知、发送消息或实现客户端。
