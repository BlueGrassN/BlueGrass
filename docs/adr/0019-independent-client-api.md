# ADR 0019：独立 Go 客户端 API 与长期会话

- 状态：已接受，记录 2026-10-11 用户指示及已实现的服务端行为。
- 确认依据：用户要求客户端登录与官网登录 API 分离，登录一次后可以长期刷新节点；后续指定 Go 或其他非 PHP 技术，并要求考虑与其他程序共用数据库时的并发。
- 替代范围：替代 D-05 的“首版通过网页取数、等待未来 API”实施路径，以及 D-16 的“复用官网登录流程”实施路径；统一数据源边界、按需分页、连接前刷新、密码与短信产品目标继续保留。

## 决定

1. 服务端采用独立 Go API，代码放在 APP 的 `client-api/`，Hytron 放置目录为 `/www/wwwroot/test-api.dos.im`，HTTP 前缀为 `/api/client/v1`。网站和证书由用户管理。
2. 读取现有账号与节点业务数据，客户端令牌和会话单独管理。业务源只读，会话写入自身 `bg_client_*` 表，不复用官网令牌，不在失败时切回官网旧登录。
3. 默认访问令牌 30 分钟、刷新令牌 180 天闲置有效期，成功续期滑动延长，无固定会话总寿命；仍执行改密、停用、删除及撤销检查。
4. 客户端每设备会话串行续期；发送前持久化原刷新令牌及本轮请求 UUID，失败重试复用同一组合，成功原子保存新令牌。默认 120 秒结果恢复窗口；不能把所有 401 都当作需要用户输入密码。
5. 用有界连接池、超时、限流、密码计算并发控制和短事务限制数据库负载；业务查询不加写锁，不自动改业务表或索引，其他程序的已提交变更在后续查询中重新核实。
6. 客户端通过 `CustomerDataSource` 和预留的 `ApiV2DataSource` 适配。适配器名称不等于 API 路径版本；HTTP 使用本实现的 v1 契约。
7. 当前节点 ID 是订阅 ID，列表只返回合格的 SOCKS5 中转节点；详情用于连接前刷新，禁止原始静态 IP 兜底。完整资产和其他协议能力须补充契约。

## 状态与验收边界

服务端代码和测试已完成，客户端适配与端到端验收尚未完成。初次交付仅放置代码；用户随后明确要求启动，Hytron 测试 API 已初始化自身会话表、启用 systemd 与开机自启并通过公网健康检查，见[运行记录](../../client-api/docs/OPERATIONS.md)。仍仅使用 Hytron 测试库，未连接生产数据库；不授权生产部署、生产数据库结构变更或 Git 提交。

D-16 的短信目标继续保留，但当前 API 只有密码登录；D-03 的其他协议、D-07 的出口验证与完整资产展示也不能因本 API 交付而视为完成。Windows 本地 Go 服务继续遵守 D-11 的进程边界，不持有业务登录令牌。
