# ADR 0007：出口验证成功后才完成连接

- 状态：已接受。
- 决策日期：2026-10-10，Asia/Hong_Kong。
- 对应事项：设计审阅报告 D-07。
- 确认依据：用户选择 A，出口检测未通过时不完成连接，TUN/VPN 保持阻断并提示重试。

## 决定

1. 首次连接、切换资源和断线重连均须完成中转认证、经所选线路的实际访问及出口 IP 检测，成功后才进入“已连接”。
2. 所有检测端点失败、超时或返回无效出口结果时，进入“失败”，报告 CONN-004，并允许重试；不能仅凭认证成功进入“已连接”。
3. TUN/VPN 验证期间及验证失败后保持业务阻断。验证只允许受控探测通道经所选中转访问检测端点，普通业务入口与 TUN/VPN 的业务转发在验证通过前保持关闭。
4. Windows 系统代理仅在验证成功后应用。首次连接验证失败不接管系统代理；已有代理会话的重连或切换失败时暂停业务转发，不能自动恢复直连。
5. 检测出实际出口与可靠的预期 IP 不符时，报告 CONN-005，拒绝业务放行。只有服务端契约能够可靠提供预期出口时才做该项比对，不把入口 IP 当作预期出口。
6. 验证完成、放行前再次检查当前资源和会话标识以及有效期，防止过期或上一次连接的迟到结果放行新会话。

## 状态与恢复

- 连接状态为“失败”时，保护状态可同时为“生效·阻断”；界面显示错误原因、重试及主动解除保护的入口。
- 重试仍通过受控探测通道；成功后才恢复业务转发，失败时继续保护。用户开始新的逻辑会话时仍执行 D-05 的资格刷新。
- 用户已明确解除保护或正常退出时，按既定停止与恢复流程处理。
- 对已验证且正常运行的连接，手动诊断时检测端点暂时不可用只记录诊断失败和上次成功验证时间，不伪造新的验证成功；诊断确认出口错误时停止相应业务会话并保持已有保护。

## 备选方案（未采用）

在检测端点不可用时允许“已连接·出口未核实”：未采用。认证或一般访问成功不能替代连接阶段所要求的出口结果。

## 验证要求

- 覆盖一个检测端点失效、全部失效、超时、无效响应、恢复成功，以及与可靠预期不符的情况。
- 覆盖首次连接、重连和资源切换，验证失败时不进入“已连接”，普通业务不通过未验证代理，也不绕行物理网络。
- 验证期间仅受控探测请求可以经所选中转发出；保护阻断不会反过来阻止检测重试。
- 验证完成前到期、切换资源或取消连接时，迟到的成功结果不能放行业务。
- Windows 与安卓、D-03 各协议的已选配置分别执行。
