# ADR 0023：资源选择页默认展示可连接资源

- 状态：已接受，客户端与完整资产接口待实现。
- 决策日期：2026-10-11，Asia/Hong_Kong。
- 对应事项：全项目复核 C01、C08；资源选择页与完整资产展示。
- 确认依据：用户选择 A；默认显示可连接资源，切换到“全部资源”查看静态 IP、开通中、到期等其他已购资源。

## 决定

1. “我的 IP”资源选择页默认采用“可连接”视图，并提供明确的“全部资源”切换入口。
2. “可连接”依据逐资源资格、配置完整性、已知有效期及本发行包支持能力判断；实际网络连通与出口仍在连接阶段验证。不能把列表中的可连接标识当作已经通过出口检测。
3. “全部资源”展示当前仍归属本人的资源，包括仅静态 IP、开通中、到期未回收及其他不可连接资源；已回收或转出的历史资源不展示，见 [D-25](0025-currently-owned-resources-only.md)。不可连接条目展示真实原因和适用操作，不能将其作为连接出口；列表缺席不能用来推断具体原因。
4. 搜索、国家、分组和即将到期等筛选结合当前视图使用，具体字段由完整资产契约提供。切换视图或筛选本身不建立连接、不切换当前活动资源；实际连接前仍按 D-05/D-19 刷新详情，按 D-07 验证出口。
5. “可连接”为空时显示“暂无可连接资源”，提供查看全部资源和刷新的入口；不能据此宣称用户未购买资源。
6. 加载中、请求失败、筛选无匹配和确实无资源采用不同反馈。空页但 `has_more=true` 时仍有后续页，不能提前给出整个视图为空的结论；只有完整资产接口明确证明当前无归属资源时，才提示“暂无资源”，不推断用户从未购买。

## 数据契约与实现边界

[D-39](0039-first-resource-preselection.md) 补充首次使用行为：没有历史选择及已有会话时，预选默认列表中第一条符合条件的资源；只更新界面，用户点击后才执行连接。空页有后续时继续按分页查找，不覆盖手动选择或将预选当作成功连接历史。

[D-40](0040-recently-connected-first.md) 确认默认列表按最近成功连接优先，其余维持接口顺序；先筛选再排序，展示层重排不改变原始分页游标、资源资格或当前选择。

- 当前 `/nodes` 只提供合格 SOCKS5 中转节点，可承接默认视图的数据基础；客户端仍须校验支持能力、完整性和已知有效期。
- 当前接口不能承接“全部资源”：需补齐资产身份、订阅关联、资格状态、不可连接原因、筛选和分页契约，不能用 `/nodes` 的结果或空列表伪装完整资产。
- 未提供的资产数量、分组或原因不编造默认值；缓存、未加载页和同步失败沿用既有展示规则。
- 本决定只确定默认视图与必要的空状态，不改变多协议范围、单活动资源、资源到期处理或其他已确认决定。

## 验证要求

- 同时存在可连接、仅静态 IP、开通中和到期资源时，默认只展示可连接条目，“全部资源”可查看各类已购资源及真实状态。
- 无可连接资源但仍有其他已购资源时，不能显示“尚未购买”；请求失败或存在后续页时，不能显示成确定的空列表。
- 筛选无匹配、跨页加载、切换视图和使用缓存的提示正确；不遗漏后续页、不混用两种视图的数据完整性结论。
- 切换视图不影响当前连接；点击连接仍重新核实所选资源并通过出口验证。
